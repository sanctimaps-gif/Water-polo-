# Motion-captured clips

Adobe Mixamo animations (FBX supplied by the user), retargeted to the game rig with `tools/anim` (only the joint
angles are stored here, no Mixamo character). Mixamo animations: royalty-free for use in projects.

| File | Mixamo clip | Used for |
|---|---|---|
| `treading.json` | Treading Water | eggbeater (all players) |
| `shot.json` | Baseball Pitching | shot wind-up (arm cocked high behind the head) and release / follow-through (shot, power shot) |
| `pass.json` | Throw Object | pass release (mirrored onto the throwing arm) |
| `dive1.json`, `dive2.json` | Goalkeeper Diving Save, Goalkeeper Diving Save 2 | goalkeeper dive, take-off to full extension (one clip per side, mirrored for variety) |
| `victory.json` | Victory | goal celebration (upper body; the legs keep treading water) |
